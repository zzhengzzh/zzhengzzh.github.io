02 / POWER ELECTRONICS2025/11 — 2026/04

有源电力滤波器设计与研究

本科毕业论文 · 独立完成软硬件设计与论文撰写

  • 面向非线性负载谐波补偿，完成三相两电平并联型有源电力滤波器设计，涵盖主电路、驱动接口、信号采样与调理电路及 PCB 设计。
  • 采用 dq 谐波检测与 SRF-PLL 锁相，在 MATLAB/Simulink 中对比 PI、多重比例—谐振及比例—重复控制（PRC）；PRC + SVPWM 方案的稳态仿真电网电流 THD 从 19.21% 降至 3.16%。
  • 基于 TMS320F28335，在 CCS 中使用 C 语言开发采样、锁相、直流电压外环、PRC 电流内环及 SVPWM 程序，实现 10 kHz 实时闭环控制。
  • 搭建 DSP 与 Typhoon HIL 硬件在环验证平台；在三相二极管整流负载工况下，补偿后电网电流 THD 从 20.15% 降至 4.86%，HIL 模型直流母线稳定于 800 V。
