Selected projects

01 / POWER ELECTRONICS2026/03 — 2026/06

GD32G553-based two-stage DC fast charging system

Control algorithm and embedded software development

  • Developed control algorithms for a T-type three-level rectifier and a three-phase interleaved Buck converter, using voltage-current dual-loop control and neutral-point voltage balancing for the rectifier and voltage-loop control for the Buck stage.
  • Wrote the DSP and supporting FPGA programs for coordinated control of the front-end rectifier.
  • Developed GD32G553 software for the downstream Buck stage, implementing ADC voltage sampling, PI control, and three PWM outputs interleaved by 120°.
  • The project completed simulation and low-voltage prototype validation, achieving a regulated 50 V DC bus and a 30 V step-down output.

02 / POWER ELECTRONICS2025/03 — 2025/08

Inverter with energy feedback

Software development

  • Developed DSP28335-based inverter software using Clarke / Park transforms and incremental PID control.
  • Implemented voltage feedback, button-based parameter tuning, and 20–100 Hz frequency adjustment in 1 Hz steps.
  • Implemented an energy-feedback path through an isolation transformer and rectifier to return output-side energy to the input.
